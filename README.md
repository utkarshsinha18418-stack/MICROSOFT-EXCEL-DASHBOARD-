# MICROSOFT-EXCEL-DASHBOARD-

Developed a Sales Forecasting & Regression Analysis project to analyze the impact of Marketing Spend and Price on Sales. Cleaned the dataset using outlier detection, performed multiple regression and correlation analysis, and applied 3-month moving averages for forecasting.

Built a dashboard to visualize sales trends, forecasts, regression results, and business insights.

Forecasted sales for the next month, quarter, and year while identifying seasonality, promotions, and SKU-level trends as key factors for improving prediction accuracy.
